ENERGIA+ — PROGETTO SCOLASTICO

STRUTTURA DELLA CARTELLA
- index.html                 Pagina iniziale / Home
- rinnovabili.html            Pagina sulle fonti rinnovabili
- non-rinnovabili.html        Pagina sulle fonti non rinnovabili
- css/style.css               Stili, colori, font e layout
- foto/                       Cartella in cui conservare le fotografie
- js/                         Cartella per eventuali script futuri

COME APRIRE IL SITO
1. Estraete tutto lo ZIP mantenendo la struttura delle cartelle.
2. Aprite index.html con Chrome, Edge o Firefox.
3. Per navigare tra le pagine usate la barra in alto (computer) o quella in basso (telefono).

COME MODIFICARE
- Testi: aprite il file HTML della pagina interessata con Visual Studio Code o Blocco note.
- Aspetto, colori, font e dimensioni: modificate css/style.css.
- Foto: mettete le immagini dentro la cartella foto e cambiate il valore src delle immagini, per esempio:
  <img src="foto/nome-foto.jpg" alt="Descrizione della foto">
- Non rinominate o spostate i file senza aggiornare i collegamenti.

NAVIGAZIONE
Su computer la navigazione è in alto con le etichette testuali.
Su telefoni e dispositivi mobili la navigazione diventa una barra fissa in basso con icone:
- Home: Font Awesome fa-home
- Rinnovabili: Font Awesome fa-leaf (come il codice fornito)
- Non rinnovabili: icona pompa di benzina fornita tramite l'immagine FontAwesome-Gas-Pump.

FONT E ICONE
I font DM Sans e Roboto Slab e le icone Font Awesome vengono caricati online. Le immagini fornite sono caricate dai rispettivi siti. Per visualizzare tutto correttamente è quindi necessaria una connessione Internet.

DA COMPLETARE
Sostituite i testi tra parentesi quadre con le informazioni della vostra ricerca. Inserite fonti attendibili e citate le immagini. Prima della consegna controllate che i collegamenti funzionino e che il sito sia leggibile sia su PC sia su telefono.
